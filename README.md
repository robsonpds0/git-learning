## Comandos aprendidos

-`git status` - Verifica o estado do repositório.
-`git add` - Prepara alterações para o próximo commit.
-`git commit` - Registra uma versão local.
-`git push` - Envia commits para o repositório remoto.
-`git pull` - Traz e integra alterações do repositório remoto.
-`git branch` - Trabalha com branches.
-`git switch` - Troca de branch.
-`git merge` - Integra branches.
